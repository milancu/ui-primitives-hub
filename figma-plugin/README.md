# UI Primitives Hub – Figma Plugin

Plugin slouží k exportu stylizovaných UI komponent z aplikace do Figma dokumentu.

## 🚀 Spuštění

```bash
pnpm install
pnpm run webpack:watch
```

## 🌱 Environment variables
Vytvoř `.env` soubor:

```env
FIREBASE_APIKEY=
FIREBASE_AUTH_DOMAIN=
FIREBASE_DATABASE_URL=
FIREBASE_PROJECT_ID=
FIREBASE_STORAGE_BUCKET=
FIREBASE_MESSAGE_SENDER_ID=
FIREBASE_APP_ID=
FIREBASE_MEASUREMENT_ID=
BACKEND_API_URL=
```

## 🛠 Použité technologie
- react-figma
- TypeScript
- Webpack
